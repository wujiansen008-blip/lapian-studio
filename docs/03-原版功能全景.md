## 三、六个标签页（真实名称与结构）

### 图1 · 框架拆解（`detailView`）

三段式布局：

1. **分镜卡片横排**：分镜1…分镜N，每卡显示「镜N」+ 起始时间（00:00 / 00:04 / 00:08…），点击可看大图
2. **口播文案**：按时间段切成独立小块（00:00、00:04、00:08…），每块单独可编辑；
   空态文案：**「该分镜未识别到字幕，请补口播/OCR后复核」**
3. **脚本总结**（右侧，13 个字段）：
   卖什么 / 卖给谁 / 吸引理由 / 促成理由 / 三段论 / 脚本框架 / 多线剧本 / 黄金3秒 /
   中段方法 / 结尾模式 / 主角场景 / 识别信号 / 实际操作 / 观看人群
4. **画面总结**（右下）：出镜人物 / 核心卖点 / 情绪基调 / 章节分布 + 总论 + 三段论提示

> 关键设计：**每个字段都以「商品/产品/品类待定」的空态文案告诉用户缺什么证据**，不是留白。

### 图2 · 分镜拉片（`storyboardView`）

**横向矩阵：行=分析维度，列=分镜**

| 行 | 内容 |
|---|---|
| 画面分析 | 缩略图 + 「分镜N」+ 每帧视觉 + 时间区间（00:00-00:04）+ **单镜「下载」按钮** |
| 内容分类 | 待补证据 / 视角待定 |
| 镜头作用 | 快速建立注意力 / 交代场景关系 / 推进信息逻辑 |
| 疑似痛点 | 开头先给冲突/疑问/反差 / 用具体场景承接人群痛点，降低理解成本 |
| 展示调整 | 勾选框 |
| 口播文案 | 画面：当前视频首段抽帧(00:00-00:04)… / 口播：未识别到稳定画面字幕 |

右上角有 **3.99 / 3.2 / 3.1** 三个分类图例圆点。

### 图3 · 爆款复盘（`reviewView`）

- 标题：上传 4 张千川投放截图
- 说明：**把素材拉片结论和真实投放数据对齐**
- 四个上传位，各自带操作指引：
  1. 投放数据总览 — 含整体消耗、ROI、成交金额、3秒/5秒/10秒播放、成交订单和趋势对比
  2. 内容分析-点击次数 — 切到「整体点击次数」，保留峰值、互动曲线、副本分析和创意要素拆解
  3. 内容分析-流失人数 — 切到「整体流失人数」，保留峰值提示、流失比例
  4. 内容分析-点赞次数 — 切到「整体点赞次数」，保留峰值提示
- 按钮：生成投放复盘（红）/ 清空三图
- 状态：`已上传 0/4，待补：…`

### 图4 · 爆款迭化（`shootingView`）★ 不是「拍摄单」

- 顶部折叠面板「我的产品信息」：`尚未填写产品资料` / `未保存` / **生成针对性裂变（20积分）**
- 主体同样是横向矩阵：
  - 行1 画面分析：缩略图「分镜N 等待视频抽帧」+ 时间 + 「该分镜未识别到人物口播」
  - 行2 **裂变思路**，每列含：
    - 标签：`槽位裂变 高优先级` / `保留原版 中优先级`
    - 槽位标题：开头钩子 / 人群/场景 / 使用演示 / 核心卖点
    - **稳定**：保留 00:00-00:04 的开头钩子位置。保留「产品/品类待定」的核心语义
    - **口播链**：v1 …（参考时长 3.5s）→「展开其余口播（另有2条）」
    - **画面链**：→「展开其余画面（另有4条）」

### 图5 · 成品视频分析（`finalView`）

- 标题：**对标视频 vs 成品视频**
- 说明：按画面主体、构图机位、口播字幕、镜头动作、时长节奏、转场顺序，判断成品是否 1:1 复刻
- 分析模式下拉：**API 深度 1:1 对比（推荐）**
- **成品分镜对比列表固定 4 段**：分镜1｜开头钩子 / 分镜2｜卖点铺垫 / 分镜3｜信任补强 / 分镜4｜结尾转化
  - 每段两个输入框：`对标：对标视频[输入]`、`成品：成品视频[输入]`
- 右侧：上传成片 + 播放器 + 成片时长 / 帧数

### 历史记录（`historyView`）

- 标题：本机记录
- 说明：**「保留最近十张图1至图5图片快照，不重复保存原视频。」**
- 操作：全选 / 已选 N 条 / **批量导出**
- 空态：暂无历史记录，完成一次拉片或分析后会自动保存在本机

> ★ 重要：原版历史存的是**图片快照**（每条的图1~图5 截图），上限 10 条；
> 我方存的是结构化 analysis + 分镜图，上限 200 条 —— 设计目标完全不同。

## 四、导出（8 项，2x PNG）

带空白检测：没生成内容就导出会被拦下并提示。

## 五、两个抽屉

**飞书抽屉**：`lark-cli` 命令、主表 appToken/tableId、分镜表 appToken/tableId，按钮：检查 / 写入 / 导出 payload。
→ **双表写入**（素材总表 + 分镜明细表）。

**算力中心**（截图 `07-api-drawer.png`）：
- 算力余额（读取失败）/ 运行模式：正式计费 / 口播引擎：本地可用
- 激活码（可显示/复制）、机器码（`dev_84ece7d2…`，可复制）
- 激活码兑换算力、刷新余额、充值算力、自检口播、**云端重析**
- 消耗记录
- 说明：**「分析、复盘和成品对比走平台后端统一托管；口播识别固定使用本地内置引擎，不消耗算力。」**
