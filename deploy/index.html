安装步骤

  1. 点上面的按钮下载安装包，双击安装（Windows 可能提示"未知发布者"，点「更多信息」→「仍要运行」）
  2. 安装完成后打开，顶部会出现橙色提示条 → 点 「去填 Key」
  3. 填入你的 API Key 后保存（地址和模型名已经预填好，不用管）
还没有 Key？去 阿里云百炼 开通，新用户有免费额度。开通后在「API-KEY 管理」里创建一个，复制 sk- 开头的字符串即可。

怎么用

  1. 左上角「选择视频」，上传一条竞品视频（建议 30 秒 ~ 2 分钟）
  2. 等抽帧完成 → 点「① 本地转写口播」（可选，但强烈建议，否则报告缺口播文案）
  3. 点「② AI 拉片分析」，等 1-2 分钟出结果
  4. 左侧六个页面分别是：拉片分析 / 分镜拉片 / 投放复盘 / 终局对比 / 逐镜裂变 / 历史记录

常见问题

现象说明
点分析没反应 看顶部是否还有橙色提示条，说明 Key 没填或填错
报告全是"待核对" Key 对应的模型不支持读图。必须用视觉模型（已预填 qwen3-vl-plus）
转写很慢 本地跑 whisper，一条 1 分钟视频约 30-60 秒，正常
分析要等很久 首次 1-2 分钟正常（要看 9 张分镜图），别以为卡死了
数据全部保存在本地电脑，只有调用大模型时才会联网
